# Body map art

`src/features/body/bodyArt.json` is generated by `build.cjs` from `parts.json`.

**Source and licence.** The figure is derived from
[“Muscles front and back.svg”](https://commons.wikimedia.org/wiki/File:Muscles_front_and_back.svg)
by OpenStax, Tomáš Kebert and umimeto.org, licensed
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The derived figure
(`parts.json`, `bodyArt.json`) is shared under the same licence; the app shows the credit under
the body map.

**What the build does.**

- `parts.json`: every painted shape of the original SVG (clones expanded), with its absolute
  transform; `mapping.json` maps source shape ids to the app's muscle ids.
- `build.cjs`: remaps the front view onto the back view's shoulder line, widens neck, traps,
  shoulders, arms, thighs and calves and narrows the waist (an original, exaggerated physique),
  splits the deltoid into front / side / rear heads along the chart's own deltopectoral line, and
  writes `{ viewBox, parts, seams }` per view.

**Regenerate.** `svgpath` is only needed here, so install it next to the script, not in the app:

```sh
cd scripts/body-art
npm install --no-save svgpath@2.6.0
EMIT=../../src/features/body/bodyArt.json node build.cjs . dark
```

`build.cjs` also writes `manga-dark.html` (a preview, not committed). After regenerating, run
`npm test` (every view draws exactly `musclesForView`) and `npx playwright test e2e/bodyMap.spec.ts`
(every muscle stays tappable).
